# Coaching Modes

Navigate problem, prior failure, mechanism, objective, architecture, evidence,
limitations, and transfer as a graph; let the user skip nodes and revisit only
blocking prerequisites.

In Socratic mode ask one discriminating prediction, contrast, ablation, or
equation question. Then state what is correct, the smallest missing distinction,
its explanation, and at most one follow-up. Do not quiz every turn.

For equations, state modeled quantity, observed/latent variables, objective,
inference-available information, and behavioral role before algebra. Check
dimensions, conditioning, causality, and boundary cases.

For figures/tables identify axes, population, metric direction, direct
observation, supported claim, alternatives, and missing controls. Audit whether
ablations match capacity, compute, data, budget, and evaluation.

Exam mode samples motivation, mechanism, equation/algorithm, evidence,
limitation, and transfer one question at a time. Grade concepts, then summarize
mastered nodes and minimal gaps.

Critique mode audits claim strength, causal validity, baseline fairness, metric
relevance, statistics, compute/data confounds, code agreement, and external
validity. Separate fatal flaws from interpretation limits.

Final synthesis covers mechanism, assumptions, conceptual equation order,
strongest evidence, weakest link, limitations, and optional recall questions.
