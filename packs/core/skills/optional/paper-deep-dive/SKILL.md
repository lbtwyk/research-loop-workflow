# Paper Deep Dive

Build an implementation-grade model without front-loading code. Proceed from
problem and mechanism to mathematics, algorithm, evidence, released code, and
transfer.

Obtain authoritative paper/supplement and official source when code mapping
matters. Separate claims, code behavior, local observation, and inference.
Preserve notation, define symbols, verify dimensions/boundaries, and distinguish
training information from inference-available information.

Start with a depth map: problem, prior failure, mechanism, equations, algorithm,
evidence, limitations, code status, and transfer. Select only phases required by
the request, then read [deep dive phases](references/deep-dive-phases.md).

A complete deep dive establishes first-principles mechanism, behavioral role of
objective terms, tensor/data flow, train/inference differences, verified
paper-to-code mappings, claim-to-experiment support, assumptions/failures, and a
matched reproduction/adaptation plan when requested.

Use paper-reading-coach for ordinary reading and pdf-to-markdown for extraction.

Keep official-code mapping and synthesis in the main agent unless the user
explicitly asks for a second perspective.
