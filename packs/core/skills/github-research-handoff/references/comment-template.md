# Research Handoff Comment Template

```markdown
## <experiment> evidence update

Status: <factual one-sentence status>

Experiment spec: `<repo-relative path>`

### What ran

<routes, seeds/checkpoints, evaluation cadence>

### Main evidence

| variant | metric direction | metric direction |
|---|---:|---:|
| ... | ... | ... |

### Render review

<observations and manifest/review-package paths>

### Interpretation

<the leading claim and the chosen comparison; mention other results only if they falsify that claim>

### Decision requested

1. <evidence-distinguishable option>
2. <evidence-distinguishable option>
```

Omit sections that add no information. If no scientific decision is required,
end with the factual next operational action instead.
