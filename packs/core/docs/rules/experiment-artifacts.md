# Experiment artifacts

- Specs live in `docs/experiments/EXP-*.md`. Contracts live in
  `docs/experiments/contracts/`. Reviews live in `docs/experiments/reviews/`.
- Load only the sections needed for the current phase. Planning: Intent Anchor
  and Current Route. Implementation: add Execution Snapshot and the contract.
  Launch or review: full contract. Evaluation: exact artifacts and Current
  Conclusion.
- Create a new EXP only for a new falsifiable claim, causal intervention, or a
  materially changed frozen data, representation, training, or evaluation
  contract.
- Bind provenance identities needed to interpret or resume. Do not add
  blanket hashes.
